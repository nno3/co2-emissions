# CO₂ emissions

Charts of country CO₂ emissions, Japan’s population against emissions, and the change from 2001 to 2002.

Joint project between me and Mohammad Abdullah Malik, we prepared the data in Orange by filtering, filling missing values, and combining tables, then drew these charts to visualise the data.

Live page: https://nno3.github.io/co2-emissions/

Open that link for the map and the Japan chart.
