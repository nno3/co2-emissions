# CO₂ emissions

Charts of country CO₂ emissions, Japan’s population against emissions, and the change from 2001 to 2002.

Joint project between me and Mohammad Abdullah Malik. The emissions are from the Kaggle dataset CO2 Emission by countries Year wise (1750–2022). Japan’s population is from the World Bank. We prepared the data in Orange by filtering, filling missing values, and combining tables, then drew these charts to visualise the data.

Live page: https://nno3.github.io/co2-emissions/

Open that link for the map, the Japan chart, and the 2001–2002 bars.
